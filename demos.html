DEMO_02 // LINEAR PROGRAMMING

二维线性规划 (LP) 可行域与单纯形顶点探索

线性规划的基本定理证明：若线性规划存在最优解，则必可在可行域（凸多面体）的某个极点（Vertex）处达到。调整下方目标函数梯度向量 $c = (c_1, c_2)$，观察目标超平面与最优顶点的实时跃迁。

目标函数权重 $\max c_1 x_1 + c_2 x_2$

权重 $c_1$ (x 轴方向): 3.0
权重 $c_2$ (y 轴方向): 2.0

约束条件系统

1) $x_1 + 2x_2 \le 14$
2) $3x_1 + x_2 \le 18$
3) $x_1 \ge 0, \quad x_2 \ge 0$
